# 国服简体中文剧情增量

序章和 4.1 活动的剧情脚本来自 2026-11-09 从国服模拟器 VDI 提取的 `configs/story`。2026-11-10 从同一客户端的 Lua 配置包补提了关卡和小径数据，并逐个比对本目录中的 132 个剧情资源文件。

- `episode_bindings.json` 记录阅读版单元对应的游戏关卡、脚本或剧情组 ID。
- `story_metadata_4_1.json` 保留本次使用的原始配置行，包括关卡标题和副标题、小径文档与对话、调查案卷、角色关卡及轶事步骤。
- 《亚特兰蒂斯谋杀案》使用 `episode` 的 20 条关卡记录。`204104` 是调查玩法配置 `activity248_const[4]` 指定的《鞋印的研究》第二段。`204100` 对应版本 PV。24 条小径按 `chapter_map_element` 的所属关卡归档，4 份调查案卷按解锁关卡另列。
- 《雪红与玫瑰白》和《糖浆井》使用活动 `14121`、`14120` 的关卡 ID。阅读版保留原文件名及旧锚点。关卡 `1412103` 关联的 `315911` 只有闭幕指令，`1412109`、`1412110` 是玩法挑战。
- 阿莱夫轶事《奇遇之夜》使用 `hero_story` 的 `35` 号记录与 `311301`—`311309` 剧情组。阅读版沿用既有轶事编号规则 `1900 + hero_story_id`。
- 序章《此即明日》使用手册分组 `101`—`106`，共 6 个剧情单元。绑定记录另列手册未引用的脚本 `100011`、`100012`。

4.1 配置还用于复核旧章中的独立对话小径。`standalone_trails_pre_4_1.json` 保留 59 条小径的元素、对话组和原始步骤，其中 16 条补入正文，43 条改回该元素实际引用的对话。《入雅典记》另有 3 条候选记录，解锁条件指向《翡冷翠之春》，引用的台词则与《复乐园》重复，暂待游戏内核对。
