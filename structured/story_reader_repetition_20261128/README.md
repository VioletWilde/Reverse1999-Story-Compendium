# 2026-11-28 重复收录修订

本轮检查五种语言的 692 份章节、3,455 个客户端原文折叠框和 3,151 条小径，处理重复收录与重复呈现。

下列数量按语言分别计数。

## 修订内容

| 问题 | 处理 |
| --- | --- |
| 客户端摘录与上方正文重复 | 移除 1,172 个无独有正文的折叠框，将其中 1,936 条独有标题卡放回对应场景位置。 |
| 视频字幕和紧邻的文字转写同时显示 | 合并 232 处重复呈现，涉及 188 个剧情单元。 |
| 小径说明和操作标签重复 | 清理 4,658 条重复字段。其中 352 条为“交互”“教学记录”等泛化操作标签，保留了经国服配置核实的实际操作原文。 |

折叠框的判定保留标点、大小写、人物名称、英语单词间隔、出现顺序和重复次数；只忽略 Markdown 排版差别。标题卡按前后对白定位，不能确认位置时保留原框。人物确实重复说出的台词、不同分支的回应和有文字差异的客户端稿继续保留。

视频字幕只与紧邻的转写比较，有语音编号时还要求编号相同。不会按重复句子全局删除文字。
