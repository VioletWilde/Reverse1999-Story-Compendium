# 国际服 3.9 剧情整理

> 版本说明：国服与国际服按各自更新进度收录，当前资源基线分别为 4.1 和 3.9。后续补录见 [2026-11-23 补录说明](../story_reader_completion_20261123/README.md)。

阅读版使用 Windows 国际服 3.9.0 的 2026 年 11 月 10 日热更新资源，以现有中文目录的章节和单元顺序为底稿。关卡标题和副标题取自国际服配置，剧本和小径分别按脚本 ID 和元素 ID 查找。序章用游戏手册的分组，洋葱头轶事《流行于世界》用轶事配置并收录相关线索、报道标题和结局评语。

3.9 初版每种语言有 993 个单元。Issue #2 修订后，英文、日文、韩文和繁中各收录 77 章、1,027 个单元和 614 条小径。其中 1,014 个单元有正文，13 个单元保留关卡信息。全量核对补入《不老春》14 条论坛小径后，500 条小径带有文档、对话或选项等正文，其余 114 条保留游戏配置中的标题、说明或操作。

- [章节和脚本绑定](episode_bindings.json) 按阅读顺序记录关卡、脚本、轶事分组和小径 ID。少量拆分和合并过的关卡沿用 `v1.2.0` 已审定的绑定，初版重新读取 3.9 客户端正文；后续补回或换入的正文部分使用仓库历史保存的官方多语脚本，详见下方修订记录。
- [资源覆盖记录](coverage.json) 记录 3.9 初版输入文件的校验值、9 个晚于本机国际服资源的中文章节、各语言空正文单元和缺少目标语言的原始步骤。原始步骤中也有测试、控制或重复文本。带有正文的分支若缺少选项文字，阅读版保留分支并标注缺译。
- [校验结果](validation.json) 记录 1,340 个脚本的图遍历、四种语言的目录链接、章节锚点、小径绑定和语言键检查。初版校验发现当时的中文页《长夜鸣笛》的“多瑙黎明”正文对应角色脚本 `312501`，国际服页面使用关卡配置指定的 `203109`。

旧篇目的脚本与关卡修订见 [Issue #2 修订记录](../story_reader_corrections/README.md) 和 [2026-11-22 修订记录](../story_reader_audit_20261122/README.md)。本文数量为国际服 3.9 初版及当时修订的历史记录；当前收录数量见 [阅读目录](../../readable/story_reader_linked/README.md)。国际服未上线的后续版本不列为漏收或缺译。
