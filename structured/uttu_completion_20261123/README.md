```powershell
git worktree add --detach ../story-client-baseline 7820ec20
python structured/uttu_completion_20261123/import_tools/unpack_sources.py structured/uttu_completion_20261123/sources ../uttu-source-cache
python structured/uttu_completion_20261123/import_tools/complete_uttu.py --repo ../story-client-baseline --cache ../uttu-source-cache --output ../uttu-reader-build
python structured/uttu_completion_20261123/import_tools/test_uttu_render.py
python structured/uttu_completion_20261123/import_tools/validate_reader.py
```

工具输出正文、各语言目录、覆盖记录和压缩来源快照。仓库首页、补录说明以及指向独立小径的跨页链接在发布整理时补入。
