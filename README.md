- 根据 [Issue #2](https://github.com/VioletWilde/Reverse1999-Story-Compendium/issues/2) 为每种语言补回 34 个剧情单元，修正《河港与海之间》等篇目的脚本错配、漏句和截断。[修订与来源记录](structured/story_reader_corrections/README.md)
- 对照 UTTU 五类目录检查现有章节标题、空正文及可对应的文本，修正两篇轶事篇名和四节串档，并为每种语言补回《不老春》14 个论坛话题、64 条帖子与回复。[2026-11-22 全量核对](structured/story_reader_audit_20261122/README.md)
- 相对本次 UTTU 目录，简中仍有 59 篇整篇未收录；英文 58 篇，日文、韩文和繁中各 57 篇。每种语言另有 13 个无独立正文的单元，包含玩法关卡和待核对的流程关卡。缺项、来源差异及无法逐页对照的条目均见全量核对报告。

国际服阅读版以 3.9 资源为基线，部分补回或换入的正文沿用仓库历史保存的官方多语脚本，论坛正文补自 UTTU 数据。具体来源随修订记录保存。
