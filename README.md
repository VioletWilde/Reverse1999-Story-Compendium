# 《重返未来：1999》剧情文本档案

本仓库当前发布国服简体中文剧情文本。正文按主线、活动、角色剧情和轶事分类，打开简体中文目录后即可按章节阅读。

## 阅读入口

[进入简体中文剧情目录](readable/story_reader_linked/zh-CN/README.md)

## 当前内容

- 数据来源为国服 4.1 版本资源，最近一次整理时间为 2026 年 11 月 10 日。
- 中文阅读版收录序章《此即明日》和国服 4.1 剧情。《亚特兰蒂斯谋杀案》含 20 个剧情单元、24 条小径和 4 份调查案卷，另收录佩施塔《雪红与玫瑰白》、伊芙琳《糖浆井》及阿莱夫轶事《奇遇之夜》。
- 章节正文保留剧情单元顺序、角色名、台词、旁白和选项文本。

## 目录结构

- `readable/story_reader_linked/zh-CN/` 是面向阅读的中文正文。
- `structured/story_text_repull_20261109/` 是本轮序章与 4.1 增量的原始脚本、分组、关卡与小径配置及章节绑定记录，用于核对来源和后续对照。
- 旧版多语言正文、电子书、PDF、临时 QA 文件和历史导出不放在当前主线中。

## 后续多语言整理

国际服资源准备好后，其他语言仍按同一套剧情 ID、脚本 ID 和步骤顺序整理。新的语言目录会放在 `readable/story_reader_linked/<locale>/` 下，中文目录作为当前基线保留。标题翻译只用于显示，跨语言匹配以结构化 ID 为准。
